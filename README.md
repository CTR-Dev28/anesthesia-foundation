# Anesthesia Foundation (pilot)

Created by **Dr. Cary Marlowe T. Remotigue**, founder of SynthaSuite.

Installable, offline web app: a pediatric-to-adult anesthesia dose reference where every dose line shows its source and verification status.

Open https://ctr-dev28.github.io/anesthesia-foundation/ on a phone, then:
- iPhone: Safari, tap •••, Share, Add to Home Screen
- Android: Chrome menu, Install app

Reference tool for qualified clinicians. It does not replace the drug label, institutional protocols or clinical judgment. Stores no patient data.
